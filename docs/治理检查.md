# 治理检查的范围

`scripts/bootstrap.py` 提供仓库级检查入口，检查本身不调用模型、业务接口或机器人。

| 命令 | 范围 |
|---|---|
| `check` | tracked 与未忽略的新文件；检查工作区差异和隐藏 tracked 标志 |
| `check --staged` | 读取 Git index 中的实际字节，检查本次暂存内容 |
| `check --head` | 读取 HEAD 的实际提交树，供推送与 CI 使用 |
| `install-hooks` | 仅为当前仓库选择解释器和 hooksPath，拒绝覆盖已有其他 hooksPath |
| `doctor --json` | 报告当前解释器、Git、hooks 与工具发现，不启动服务 |

检查拒绝运行/凭据路径、明显密钥或 token、符号链接、过大文件、Python 语法错误、Git 空白冲突和隐藏 tracked 标志。错误只报告路径和类别，不回显敏感值。

这是轻量治理检查，不保证发现所有形式的秘密，也不执行许可或全部历史审查。维护者需另行检查提交来源、第三方声明及隐私。测试使用临时仓库和合成字符串，不保存真实凭据。

Git hooks 可以被人为禁用，因此同一检查还在 CI 运行；项目规则禁止绕过。本检查不提供通用生产发布器或 Codex 远端命令拦截 Hook；离线部署入口与实例生产维护各有自己的边界，不能声称本检查已强制阻止所有潜在部署方式。
