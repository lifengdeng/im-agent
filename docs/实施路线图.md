# 扩展方向

以下是后续扩展方向；现有接口和限制见[能力边界](数字分身能力边界.md)。

| 方向 | 内容 |
|---|---|
| 多轮协作 | 补问、会话恢复、进度更新与取消，并保持原任务及执行绑定 |
| 模型接入 | 更多能力选择 provider，以及明确的请求范围和用量记录 |
| 工程适配 | 复杂依赖 bundle、更多运行语言和可信 adapter |
| 权限策略 | 细分能力的授权范围、可共享工作方法与私人记忆装配 |
| 主动审阅 | 接收有来源、去重标识和通知范围的事件；平台采集器由实例提供 |
| 升级与恢复 | 更通用的实例版本采用、状态兼容检查和恢复工具 |

扩展沿用固定源码、能力合同、身份隔离和未知状态先对账的约束。工程升级与应用发布分别管理，开发目录改动不直接替换运行版本。
