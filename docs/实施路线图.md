# 能力路线图

| 能力 | 当前实现 | 后续工作 |
|---|---|---|
| 源码治理 | 仓库 hooks、源码检查及 Windows/Linux CI | 每次发行固定提交，维护来源与第三方清单 |
| 飞书闭环 | 长连接受理、官方回复与回读、独立账本 | 多轮补问、取消和对账工具 |
| 能力选择 | 规则路由与显式模型选择，未知调用不自动重试 | 扩展受控 provider 和更细能力策略 |
| 本地工程 | 独立 Git 快照、1–8 项能力及 JSON 桥接 | 复杂依赖 bundle 与更多可信 adapter |
| 工程版本与恢复 | 固定合同、旧请求绑定、离线 resident 与版本观察器 | 各实例自己的同状态升级和恢复验收 |
| 主动审阅 | 可复用执行与交付账本 | 有来源、授权范围和去重标识的事件入口 |
| 公开展示 | 个人权属与仅查看/fork方向已确认 | 审定源码、隐私复核与干净公开发行根；暂不添加许可证 |

应用升级与工程升级分别管理。通用功能通过合成工程和隔离测试验证；实例发布通过各自维护流程执行，文档与源码提交不会替换生产进程。接入验收见[实例接入清单](实例接入清单.md)。
